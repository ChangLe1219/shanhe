# 山河局 · 一城风云

一款浏览器即可游玩的架空王朝人生模拟 RPG 原型。玩家随机生成出身、性别、天赋与多维属性，在澜州城里经营铺面、入仕、结交势力、追查旧案、议亲成家。各条路线通过事件、资源和人物关系彼此影响。

## 本地游玩

直接用浏览器打开 index.html 即可，无需安装依赖或构建。

## 当前原型内容

- 6 种随机出身、男女角色、6 种天赋、7 项随机属性；可重新抽取角色。
- 每日 3 次行动，行动包括查案、经营、入仕、结交与修习。
- 朝廷、商会、漕帮三方势力态度；事件分散在多种行动中，并回避最近重复出现的事件。
- 经商会遇到不同客流与订单：富家客大单、商队补货、街坊零售、货物受损和雨天冷清都会改变当天盈亏。
- “河仓旧账”主线，三条线索导向三种结局。
- 人物好感、议亲、婚姻与子女传承。
- 人物、资产、武学、背包四个可切换面板；练功可选招式，扩建铺面会提高后续收益与家业估值。
- 自动保存到当前浏览器的 localStorage。

## 文件

- index.html：页面结构
- style.css：响应式界面
- game.js：角色生成、行动、事件、主线与存档

当前是用于验证玩法方向的单城原型，世界地图、长篇人物剧情、真实升官制度和多代家族经营尚未展开。
