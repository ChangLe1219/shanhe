# 山河局 · 商路与家族规则

更新：2026-10-29。当前系统扩展版本为5，沿用版本2存档并自动补齐字段。旧存档中的人物、银两、产业、剧情选择和自定义事件会保留。

## 商路：先算一整趟，再看卖出的数

货市有粮、盐、茶、绸、药、铁、瓷器、棉布、纱布、纸张十种货。城市的基础供需不同，例如云州便宜的绸与瓷、河阳便宜的粮与棉布、临川便宜的纱布和纸，可以卖到相应紧缺地区。

每城每货有自己的库存，初始量约为 `42 / 城市价格系数`。买货减少库存，卖货增加库存；每天向基准补回或消化1单位。库存越紧，价格越高。日期带来小幅波动，商才和合筹术改善买卖折价。

买卖商品不消耗行动点，只受正整数、货市现货、仓容与银两限制。货市支持按每笔数量交易，也可一键全部购入或全部售出；“全部购入”会计算当前库存和剩余仓容，仅在银两足以买下可装下的全部现货时开放。基础仓容30，货栈每级加20。它是玩家全局持货上限；产业另有自己的原料与产出仓。

买货按平均成本登记，卖出时记收入、对应成本与毛利。赠货、出身物品和自有产业提取的货，没有再次购入成本；其生产经营费用在产业账里。销售毛利不是整趟净利，还要扣路费、佣金、途中损失与日常支出。

## 行旅距离与报价

可选任意可达城市，系统按现有交通网络选择耗时较短的通路。相邻城市一段耗时为两地舆图距离约每13单位一天，至少一天；险度3的路段额外加一天。显示里程按每一天80里折算，是便于游玩的架空尺度。

基础路费为每天8两，出发时一次收取。护航佣金为：

`申报货值 × 护航费率 × (1 + 计划天数 × 0.18) + 计划天数 × 3`

结果向上取整。货值按出发时所在地的货物买价登记，保价不保障你在目的地希望赚到的高价。佣金随距离和货值上升，不会因改走远路反而更便宜。

| 独行 | 0 | 0 | 无 | 无 |
| 长风镖局 | 70 | 3.5% | 受损申价的75% | 关系不低于-35 |

签约只启程，不瞬移。行旅中按“继续行路”逐日推进，完成全程后抵达。路上无法买货、置业、修习或拜访；日常家用、产业与来信仍会结算。

## 路上的风险

每天遇事概率受路线险度与货值影响。可能遇山匪、关卡或风雨。长途累计风险通常更高，因为要走更多天。

**无护航遇匪必有损失。** 可以交现金保货，也可以凭谋略、武艺、交际与黑旗、夜渡关系减少弃货比例，但不会靠高属性把损失降到零。没有钱也没有货时，仍会承担伤势与盘缠代价。

有护航时可交由队伍迎敌。胜算由护航战力、玩家武艺、与护航方关系和路线险度共同决定。胜则货物保全；败则损货，并依签订比例赔付。每趟累计赔付不超过原申价，瓷器因易碎会有更高实际折损。主动弃货或冒雨损坏不按败战保险自动赔付。

关卡可照明目缴费取得票据，也可私下打点并增加恶名，或拒付等待复核。持有盐引凭照或官府关系足够时，复核不额外拖延；否则增加一天。风雨可停靠增加一天、冒险损货，或亲自加固承担疲劳。

所有途中处置进入本趟记录。存档会保留尚未走完的行程、护航合同、申报价与待决事件。

## 产业不只是每日收银

现有八类产业：铺面、田庄、药庐、客栈、匠坊、货栈、织场、瓷窑。每城每类可到5级。异城产业继续结算，但实物产出必须到当地提取。

- 稳健经营：正常收益与风险。
- 扩张揽客：净营业收入乘1.4，风波概率乘1.7。
- 惠民经营：收入乘0.8，风险乘0.7，每七日增加声望。

护院0—3级，升级费用为45×新等级，每级每天维护1两。护院降低被觊觎的概率，也在实际周旋时提供助力，不保证永不出事。

药庐每七日消耗药材、匠坊消耗铁、织场消耗粮作工食、瓷窑消耗铁作窑具维护。每轮按等级消耗。新产业附两轮原料；采购可一次补四轮，含代采费用。原料在产业仓内，不会从路上的货箱偷偷取走。断供后持续暂停收入，补料才恢复，不会第二天凭空复产。

田庄、织场、瓷窑每七日产生实物，存入当地产业仓，上限200。提货受玩家仓容限制，满仓时只提可容纳部分。银钱收入代表其他常规营业，产出代表可额外调运的自留份额。

置办和扩建产业只消耗银两，不占行动点。产业可能遇到税单、勒索、恶性竞争与查账。可花钱息事、凭本领人脉与护院周旋，也可停业整理证据。周旋失败会赔付或停业，停业期间维护费仍在。经营要留周转钱，不宜把所有银子立刻变成升级。

基础生活费为每日3两，家眷与扩建宅邸另加少量家用；比旧版每日5两下调。已有官路身份者另按官阶每日领取3—12两俸入；产业日结、事件奖励与商品买卖也会进账。家业页的“日结”逐日列出产业、俸入、经营支出与家用。短工仍是无产业、无官阶时的稳定谋生办法。

## 修习与人脉

自行研习免费，熟练+5、属性+1；名师指导约28两起，熟练+10、属性+2，相关势力关系可降低学资；切磋8两，熟练+8，有机会额外提高属性，也可能受轻伤。每次占一行动。

熟练每25点突破一次，相关属性判定增加1.5个百分点助益，最多6个百分点，最终概率仍有上限。闭关可选7或30日，每日3两学资，并另计日常开销；要事会使闭关提前停止。

人脉有“已结识、本城、天下、异性姻缘”视图，可按势力筛选、按好感或城市排序、检索姓名身份和所在城。固定人物之外，每城每14日开放一次雅集，花8两茶资，生成至少两位成年异性与一位其他来客；雅集不占行动，登门初识仍需行动。已知异地人物可书信拜访，基础邮资3两，约两日后收到回信。薄礼、托问近况有额外花费与不同助益。

每月有机会让一位适合行旅的 NPC 前往相邻城市，已结识者会留下行踪信。不是每次点击都变位置。已经入家的配偶安居宅邸，不随普通人物的月度行旅迁走。

## 安家、正配与妾室

先置宅，再议亲。第一进院落120两，扩建成本递增。每进可安居三位配偶，子女另外计；所以正妻始终只一位，妾室没有固定人数封顶，但需要持续扩建和负担家用。

正妻/正夫：双方成年、异性、已结识、对方无既有婚配，好感100，正配空缺，宅邸有空间，婚礼费180两与一行动。

男角色纳妾：已有正妻，好感至少45，对方为平民或手艺人层级且愿以侧室身份结亲，费用100两与一行动。高门子女、显贵、官族和不愿为侧室者不能纳为妾。并非每个低身份人物都接受侧室身份。女角色结正夫；合适且愿意的低身份男性可作为“侧夫”，规则与妾室相同。

本版先采用好感与身份规则，不做强制政治婚约或父母包办。新增的家族来往、借债、合作、纠纷、家庭分工与教育剧情，会在婚后逐渐发生。

## 生育、嫡庶与族谱

安居宅邸所在城、家用充足、双方年龄合适且开启添丁计划时，自然受孕概率为每月24%，孕期270日。玩家可在家眷页主动相伴：每位配偶每天最多3次，每次有12%受孕机会；前两次不占行动，第三次消耗1行动。夫妻、妾室与侧夫均可有子女，生产后留有恢复间隔；行旅中不会启动新的孕期。

正妻/正配所出记嫡，妾所出记庶；区别记录在族谱，不把能力自动分成高低。男女、嫡庶均可接受家学、指定传人。族谱保存父母对应、房支、历代家主与退居、去世记录。

三岁起可授业，每十日至多一课，花12两与一行动，提高对应家学5点，最多100。可提前指定传人，正式交家需满18岁。没有把未成年子女放进婚配候选名单的功能。

## 传家与衰老

可在寿尽前选择成年子女传家；家主年老寿尽后，若有成年子女，也能继续接续。寿命受根骨与气运影响。出生与家中寿终按日自动结算并记入近事、家谱；子嗣页可查看孩子并为其更名。无合适传人时可保留本局存档，不能凭空创造一个成年后辈。

直接完整转交：现银、货物、产业、宅邸与家族档案。旧家主退居长辈或记为先辈，原配偶不成为后辈的配偶。

不直接转交：个人官职履历、普通门派身份、完整熟练、声望与道路阅历。后辈有自己的属性，家学影响初始能力；父辈走过的道路留下传习助力，相关修习获得更多熟练与阅历。部分人脉与势力关系保留为门荫，不等于全部复制父辈交情。

自立山门属于最高领导身份，可以安排交接。传人须有至少25点武道家学，否则不直接授予掌门。官职没有可直接继承的例外。当前职位为履历与成长层级，完整科举和官署权限还未展开。

“岁时经营”可推进30、90或360日，每一天都结算产业、原料、家用、孕期与年龄。普通随机遭遇在快进期间跳过；到期主线与家族待决事件仍会暂停快进并等待玩家选择。出生和寿终不要求额外选择。适合观察长年经营与子女成长，也不会跳过生活成本。

## 红袖坊与兑换码

红袖坊仅对成年角色开放。听曲（8两）与题诗（12两）提供轻量属性成长，不占行动；请掌柜引见成年异性（24两）消耗1行动，会将新人物记入人脉并建立初始好感。互动围绕曲艺、茶酒、消息和交游，不描写露骨内容。

“更多 → 兑换码”只提供兑换码输入框，奖励由项目根目录的 `redeem-codes.txt` 配置。每行采用纯文本格式：

```text
山河测试礼|silver=500|health=20
行商测试礼|silver=1200|routes.trade=10|skills.account=15
```

参数只接受白名单里的正整数增加值，涵盖银两、健康、声望、善恶、行动、属性、道路、技能、货物、势力和人物好感。修改配置文本后，将它与游戏文件一起发布；每个兑换码的使用记录随存档保存，每个存档只能兑换一次。静态网页中的配置对玩家可见，不应放入正式线上发行的秘密奖励码。

## 手机布局

竖屏采用固定资源条和六个底部入口：江湖、货市、家业、人脉、家族、更多。家族可直接触达；地图、修习、任务、工坊、红袖坊与兑换码在“更多”集中列出。江湖页也有快捷入口。

手机隐藏桌面侧栏、山水长横幅与常驻属性栏，属性通过“人物档案”查看；当前功能页独立滚动，底部导航始终可用。长剧情仍需在页内阅读，但切换功能不必滚回整张页面顶部。
