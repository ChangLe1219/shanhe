# 山河局 · 长线玩法蓝图

本文保留长期设计方向。2026-10-29更新：运输护航、产业运营、人脉书信、婚育家谱和世代传承已先行落地，具体规则以《商路与家族规则》为准。下文各路的深度经营仍是未来方向，不应将整个章节理解为全部已实现。

## 一、当前可玩的闭环（已实现）

随机出身与属性 → 每日三行动 → 六道路行程与选项 → 阅历塑成主道路 → 连续剧情与随机交叉 → 行旅、贸易、置业、修习、拜访 → 结局后继续经营与接收余波。

目前有八道十六城、十二方势力、三十名初始人物、十二出身、十二天赋、八项属性、十种货物、八种产业、七种修习。内容为四十一段连续篇章、一百四十二段随机遭遇、六段延迟余波、十一段系统风波，共二百段事件、五百九十八个选择。

现有闭环增加了库存、货物成本、按距离运输、护航与保价、盘查与山匪、经营方针、原料与护院、书信与月度人物迁居、婚配与生育、嫡庶族谱、家学与成年后代传家。衰老和寿尽会真实发生。独立回合战斗、完整官职权限与考试、NPC自主目标和国家战争尚未实现。

## 二、扩张顺序

不要同时塞入十套互不相连的菜单。优先让现有道路各出现一次更深的经营循环，再让这些循环交换资源与冲突。

| 阶段 | 应解决的问题 | 新闭环 | 完成标志 |
| --- | --- | --- | --- |
| 第二卷：生意与人手 | 产业现在主要是数值收入 | 订单 → 备货 → 雇工 → 运输 → 验收 → 信用 | 商路选择影响产业与人手，不靠无限点击赚钱 |
| 第三卷：门派与官署 | 路线头衔当前仅为阅历称号 | 加入组织 → 职责 → 俸禄或分成 → 权限 → 考核 | 职位带来具体行动，也带来必须承担的事务 |
| 第四卷：地方与灾年 | 世界仍主要由玩家触发 | 粮价、治安、疫势、水患 → 事件 → 公共结算 | 不做某件事也有可解释后果，且能清楚看到原因 |
| 第五卷：伙伴与家族 | 固定 NPC 主要提供信任与剧情 | 共同目标 → 合作 → 冲突 → 长期关系 | 人物有自己的计划，不是单一好感进度条 |
| 第六卷：天下与世代 | 大世界缺长期时间尺度 | 地方治理 → 国家变动 → 产业传承 → 下一代视角 | 旧局留下的制度、债务与声望能进入新一代 |

## 三、六路各自要有的经营

### 武道：经营实力、信誉与一个能容人的组织

短期循环：训练 → 选择委托 → 配置招式与伙伴 → 护送或交手 → 处理伤病与报酬。长期循环：师承 → 功法理解 → 门派责任 → 武林公议 → 传授与组织规则。

招式应有目的而非只分等级：制止、护卫、追击、脱身、破甲、点穴。以守护为核心的角色和以突袭为核心的角色，应能用不同配置完成同一委托。伤残不应只能宣告角色报废，可引入改良武学、教学、器械与经营转向。

门派经营可包含学田、药材、讲武、弟子工食、护送委托、内部申辩。资源不足会产生真实两难：接不接不合意的富商资助、允不允许弟子外出谋生、救济是否要限制额度。武林声望不直接等于组织忠诚。

### 行商：经营供应链与信用

订单不是凭空刷新的奖励按钮。它应来自当地需求：军镇需粮铁、城镇需盐、疫区需药、书院需纸、门派需器械。货物应有数量、品质、交期与违约条件。

产业从纯日收转向投入产出：田庄消耗种子与人手产粮，匠坊消耗铁与燃料产工具，药庐消耗药材提供诊疗服务，客栈消耗粮与维护换住宿收入。产业升级增加规模，也增加管理与供给要求。

信用至少分三类：履约信用、财务偿付、商誉。平价赈售能提升商誉，却未必立刻改善偿付能力；严格履约能提高信用，却不代表买主道德高尚。银行借贷应有风险上限与清楚破产退路。

### 官路：经营权限、责任与行政能力

初期可为代书、吏员、幕僚、考生，之后再决定通过科举、荐举或军功进入职官序列。每条入口都应有优势与依附，不是只差一组数值。

官职必须对应权限：调档、签押、巡查、征调、用印、裁定、拨款。权限同时带来考核和限制。一个县丞不能随意调动全州军队，也不能凭个人好感取消刑名。

治理需要预算与时间：修堤、治安、赈济、教育、道路争夺同一批银钱和人手。官声最好区分上级考成、民间信任、同僚协作；三者不总一致。被撤职并非游戏结束，可以保留人脉、经验与责任转入其他道路。

### 绿林：经营生存、内部共识与退路

初期可以是耳目、运私货者、山寨客卿，不必直接杀人入伙。之后才逐步经营粮仓、隐蔽度、巡山、分配、纪律、对外交易。

山寨应有不同人群：能战者、伤员、老人、孩童、手艺人、被迫入伙者。只按战斗人数计算生活，会自然制造内部不公。玩家要能选择不同分配规则，并看见后果。

行动包括截获非法货物、走私、破坏、劫运、营救、情报交易，但风险必须具体：通缉、暴露暗线、失去村庄支持、引发围剿、影响其他道路。招安不是一个“洗掉恶名”的按钮，应分身份核验、具体罪责、文书担保与生计安置。

### 学问：经营资料、机构与公共发言

基础循环：采集资料 → 核验 → 写作 → 资助与刊印 → 读者反馈 → 勘误。收益可以来自教书、代书、编修、出版与受聘。

资料必须有来源与可靠度。口述不天生低于官文，官文也不天然是真相。多个来源彼此印证后才能形成更强证据。某些线索只能由信任足够、身份合适的人获取。

书院经营包括学田、师资、藏书、住宿、课程、招生与资助独立性。知识传播后应改变部分社会状态，例如识字降低契约诈骗、地图降低旅途损耗、农书改善产量。不能让写书只换成一笔即时声望。

### 医道：经营照护与供给网络

基础循环：问诊 → 检查 → 形成判断 → 选择处置 → 随访 → 修正。避免以“选中正确药名”代替全部医疗，也不必追求真实医疗教学；游戏内医术属于架空规则。

药材供给、质量、成本与病人支付能力需要同时考虑。公筹、赊诊、商业资助、官办经费各有相应的限制与优势。不得把无限免费诊疗的成本藏到系统外。

疫事应关联饮水、交通、居住、信息报告与资源配给。医者也可以参与司法鉴证、矿病调查、运动损伤、边军医疗与公共卫生，天然与其他道路相连。

## 四、还可增加的道路与生活层

农桑：租地、种植、灌溉、种子、农时、灾损、地权、粮贷。与行商共享产出，与官路共享水利和土地，与医道共享灾年健康问题。

百工：采矿、冶炼、工图、质量、学徒、订单、工伤、安全。成果能改变战争、交通和日常生活，不只是打造更高数值的武器。

舟海：造船、船员、航线、季风、海图、保险、海难救援、港口许可。与贸易、官路、绿林和学问都存在清楚接口。

文艺：戏班、说书、书画、刊印、赞助、舆论与身份流动。可让“文化生活”独立于考试和写政论文。

驿传：递信、急件、路线规划、消息时效、失联与见证。可做连接全部道路的信息层。

家居生活：居所、饮食、陪伴、爱好、乡里归属。要让休息本身有叙事价值，而不是永远作为收益较低的劣选。

这些不必立刻全变成新的主道路。可以先作为已有道路的专长与副业，确认闭环足够独立后再升级为正式道路。

## 五、人物、伙伴与家族

关系建议拆成信任、亲近、立场兼容与共同经历。一次慷慨赠礼不应自动解决价值冲突；高信任的人也可能拒绝与你做某件事。

伙伴有职业、擅长、牵挂、资源与不可越过的底线。邀请合作要说明任务、风险与分配。伙伴会提出自己的目标，不应只在玩家菜单里等待。

婚姻如加入，应属于双方人物关系的选择。婚约能产生家产、社会关系、居所与责任变化，但不能把对方简化成加成道具。独身、伙伴、收徒与结义都应有同等完整的长期生活。

世代传承应让后辈继承部分家业、技术、债务、名誉与故事，而非完整复制上一代的所有属性。下一代可以反对上一代的道路，既有制度与人际后果仍会延续。

## 六、让世界在玩家之外发生

新增世界状态时，每一项都要有来源、可见征兆、干预途径与结算说明。例如一州粮价由产量、储备、运输、需求、政策共同影响，不宜因为随机数突然翻三倍且无法解释。

建议世界状态：粮储、物价、治安、疫势、民心、交通通畅度、军需压力、财政余量、派系紧张度。每期只更新少量相关状态，并留日志说明。

大事分为三个阶段：征兆、行动窗口、结算。春汛先有裂堤与水位，玩家有时间筹工料与疏散；没有参与也应看见修堤者、灾损与后续价格，而不是等玩家点按钮才决定下不下雨。

NPC 自主行动应保持可解释：商人调货、官员争拨款、寨子找粮、医者转诊。不要用一句“世界很大”掩盖全靠随机的状态变化。

## 七、超大文本的组织方法

推荐以“世界公共事实 + 组织目标 + 人物弧线 + 事件节点”四层维护。每次扩写新卷，先写公共事实，再分别写道路入口；最后写交叉节点与结局余波。

每卷目标可为：1 条公共主线、6 条道路线各 6—10 章、8—12 条人物支线、80—150 段地区随机事件、至少 12 段长期余波。数量只用于规划，不作为当前已完成宣称。

把内容分为四类：可重复生活事件、一次性支线、连续主线、世界状态事件。不要让每个小事件都从相同的“官商勾结”起手，也不要把所有人物都塞进同一个阴谋。

建立内容验收：无死选、无失效引用、无不可能前置、无未实现结果、无过量收益、每条分支能到达某个有意义的状态。自动校验解决结构问题，试玩与编辑解决叙事问题。

## 八、技术扩展原则

继续把规则放在 engine，把叙事放在 content，把页面放在渲染层。增加 NPC 日程、订单或战斗时，先定义独立状态、行动接口与存档迁移，再写上百段依赖它的内容。

下一步优先补：经济约束与订单、带品质的物品、可见的任务条件差额、NPC 支线、可导入的世界实体格式。再处理自主世界与世代，不建议先堆更多纯日收建筑。

支持作者不代表允许内容执行任意代码。新增数据协议应仍有严格校验、稳定 ID、版本说明与错误提示。旧存档至少需要可导出、可回退，不能在一次扩写后静默损坏。
