# 山河局 · 万象江湖

可直接在浏览器游玩的 H5 文字经营游戏与可扩写文本底座。没有第三方运行依赖。

## 游玩

双击本目录的 `index.html` 即可开始；或运行：

```text
node build.js
node server.js
```

打开终端显示的 `http://127.0.0.1:4173/`。停止服务器按 Ctrl+C。也可将 dist 中的文件部署到任意静态网站。

## 已完成内容

- 12 种随机出身、12 种天赋、8 项属性；姓名可编辑，出身不锁职业。
- 武道、行商、官路、绿林、学问、医道 6 条动态道路。
- 8 个地区、16 个可旅行城市、12 方势力、30 位初始人物，后代接家时还会出现新一代游历者。
- 200 段事件：41 段连续篇章、142 段随机遭遇、6 段延迟余波与11段系统风波；共598个选择。
- 公共河仓案 4 种结案，六路各 4 章与 3 种终章选择；终章后可继续自由游玩。
- 10类货物，紧凑货品卡与整批购入 / 售出；交易和置业不消耗行动点，地图展示各城盛产、稀缺与参考毛利。
- 8类产业，经营方针、原料库存、实物产出、护院与停业风波；7项修习可自学、请师、切磋或闭关。
- 人脉按好感、势力与城市筛选；每城定期开办雅集补充成年异性人选，异地书信，人物偶尔迁居。
- 安家、正配与妾室 / 侧夫、伴侣相处与主动添丁、嫡庶记录、家学、族谱与成年子女传家。
- 每日生活费下调；官阶按级领取俸入，家业页按日公开产业、俸入和家用账目。
- 红袖坊可听曲、题诗、认识成年异性；玩家只需输入兑换码，奖励由根目录 `redeem-codes.txt` 配置，兑换记录随存档。
- 成就簿涵盖六道、行旅、贸易、产业、修习、人脉与家族人生；解锁记录写入当前存档。
- 手机竖屏使用固定资源条、压缩后的六项底部导航（含家族直达）、紧凑货物卡；双击放大由视口设置与触摸事件拦截。
- 家族页可快进一个月；快进跳过普通随机遭遇，到期剧情会暂停。出生与寿终自动记入族谱，子嗣页可查看并更名。
- 属性判定、资源门槛、势力关系、个人信任、分支标记、直接与延迟后续。
- 自动本地存档、JSON 存档导入导出、内容包校验与导入、完整事件库导出。

独立回合战斗、真实官职权限与考试、自主势力战争尚未实现。官位与普通门派身份不直接继承，后代保留家学与部分人脉助力。自创山门的掌门可由家学达标的后辈接续。

## 从文本开始扩写

- `docs/剧情文本全卷.md`：完整可读剧情，约4.5万汉字；包含选项与结果，系统场景动态结算另有说明。
- `docs/商路与家族规则.md`：运输、护航、产业、人脉、婚配、生育、传承与手机布局的具体规则。
- `docs/世界设定集.md`：时代、地理、势力、人物、公共事实和创作约定。
- `docs/内容创作指南.md`：字段、条件、效果、判定、分支、延迟后续与示例。
- `docs/长线玩法蓝图.md`：现有边界与未来系统规划。
- `docs/事件索引.md`：全部事件 ID、类型与道路对照。
- `content/full-content.json`：生成的标准 JSON 全库底稿。

最方便的方式是在游戏「内容工坊 → 扩写编辑器」改示例、校验并导入。浏览器导入与源码修改为两种方式；全库底稿是导出物，永久扩写请改 content 源文件后重新构建。

## 源码结构

```text
content/world.js       世界数据与所有固定实体
content/encounters.js  76 段随机遭遇
content/chapters.js    连续篇章与延迟余波
content/expansion-world.js 新商品、人物、护航与产业配置
content/expansion-events.js 六路续篇、遭遇与系统场景
content/life-events.js 家事与产业经营剧情
engine.js              可在 Node 中独立验证的规则引擎
systems.js             运输、产业、人脉、婚育和传承系统
ui-expansion.js        新功能页与手机导航
game.js                H5 页面、存档与内容工坊
style.css              手机与桌面布局
expansion.css          手机固定导航与功能页布局
tests/                 引擎、剧情与经济边界测试
build.js               校验内容，生成总卷和 dist
server.js              本地静态预览
legacy-v1/             保留的原单城原型及旧存档入口
```

## 验证

```text
node --test tests/*.test.js
node build.js
```

本轮自动兼容上一版万象江湖存档；仍与 legacy-v1 单城原型分开。自动存档依赖当前浏览器 localStorage；不同域名、浏览器或设备之间请通过存档文件迁移。关页不会自动推进游戏日。
